### Naturalist 2.0.1 Changelog

- **_Removed Essential integration._**
- Fixed Fabric dependencies
- Added removal configs for new animals.
    - Adjusted configs so they are now grouped into land animals, aquatic animals, and bugs.
    - Added a "Remove All Bugs" config `(i see you raspmary)`
- Added configs for Parrot/Bird flight and Bird slow-falling
- Fixed Piranha & Shark attack animations
- Removed GeckoLib animation file artifacts
- Fixed mob animations `(namely Moles)`
- Added Banner rendering to Elephants and Mammoths
- Fixed mount Player rendering with mods like Not Enough Animations & Personality
- Knapsacks no longer disappear in Survival and can be used on Vanilla/modded mobs, and are now age-gated.
